# Iris Species Classification Using Machine Learning

A machine learning project that predicts Iris flower species from flower measurements.

## Features

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature scaling
- PCA and LDA experiments
- Multiple machine learning models
- Model comparison
- Prediction probability
- Interactive Streamlit application

## Models Used

- Logistic Regression
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Support Vector Machine
- Naive Bayes

## Dataset

The Iris dataset is loaded using sklearn.datasets.load_iris().

## How to Run

pip install -r requirements.txt

streamlit run app.py
